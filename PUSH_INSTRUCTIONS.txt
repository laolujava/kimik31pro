步骤 1: 在 GitHub 上创建新仓库
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 访问: https://github.com/new

2. 填写信息:
   Repository name: api-tutorial-examples
   Description: Complete API tutorial with Python, JavaScript, and Java 
                examples - authentication, streaming, error handling, 
                token billing
   
   ⚠️ 重要: 不要勾选以下选项（我们已经有这些文件）:
   ☐ Add a README file
   ☐ Add .gitignore
   ☐ Choose a license

3. 点击 "Create repository"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 2: 推送代码到 GitHub
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在终端中运行以下命令（将 YOUR_USERNAME 替换为你的 GitHub 用户名）:

cd /g/aicode6/api-tutorial-examples

git remote add origin https://github.com/YOUR_USERNAME/api-tutorial-examples.git

git branch -M main

git push -u origin main

Q: 推送时提示 "Permission denied"
A: 确保你已经配置了 Git 凭据或 SSH key
   参考: https://docs.github.com/en/authentication

Q: 推送时提示 "remote: Repository not found"
A: 检查仓库名称是否正确，确保已创建仓库

Q: 如何更新远程仓库?
A: git add .
   git commit -m "Update message"
   git push

Q: 如何克隆到其他机器?
A: git clone https://github.com/YOUR_USERNAME/api-tutorial-examples.git
